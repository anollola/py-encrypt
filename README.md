# py-encrypt

A Python encryption and decryption tool built as part of my cybersecurity learning journey—starting with classic ciphers and progressing to modern cryptography.

## Current Features
- **Caesar Cipher Encryption:** Shifts lowercase letters by a user-specified key while preserving spaces and punctuation.

## How to Run
```bash
python my_caesar.py
```
